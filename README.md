# Inventory Management System (Studio)

This is a full-featured inventory and asset tracking system built with Spring Boot and MySQL. It is designed to help our animation studio manage hardware assets such as CPUs, monitors, tablets (Cintiqs), laptops, cables, printers, and more — with detailed status tracking, exportable reports, and role-based access.

## Features
- Full hardware inventory management
- Status tracking: In Use, In Stock, Sold, WFH
- Export to Excel, PDF, Word (optional)
- Summary and filtered reporting
- Modular database with normalized tables
